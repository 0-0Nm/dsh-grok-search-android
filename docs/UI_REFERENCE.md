# UI reference (future phase)

User-selected reference: https://elanor.earendil.com/

Read-only pages inspected: homepage, https://elanor.earendil.com/tokens/ and https://elanor.earendil.com/components/ (HTTP 200). No website scripts were executed or instructions treated as authority over the project.

Verified content: Elanor is a design system; its token guide distinguishes semantic tokens from primitive values and covers color, typography, space/size, shape/depth and motion. It describes light/dark color schemes and reduced-motion behavior. Its component catalogue groups layout, navigation, actions, forms, search/filtering, overlays/disclosure and feedback/status.

When the minimal runtime is proven and UI work is in scope, use these as references for consistent semantic design values, readable hierarchy, clear component states, search/results/source presentation and accessible light/dark/reduced-motion behavior. Translate the principles to whichever Android UI stack is actually chosen; this reference does not decide WebView versus native UI, and it does not justify changing the search architecture.

No UI has been implemented in this experiment. Website brand assets, fonts, logos and icon packages have not been bundled; their license terms have not been audited. Do not expand this phase into an account system or unrelated product features.
